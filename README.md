# Biblioteca de Videojuegos

Backlog personal de PS4/PC, compartido con mi primo.

**Tecnologías:** Python 3
**Cómo ejecutar:** `python main.py`

Versión 2 (Completada): El sistema fue refactorizado a Programación Orientada a Objetos (POO). Se separaron las entidades en módulos independientes (juego.py y usuario.py) y se implementó composición.

Próximo paso (V3): Implementar persistencia de datos leyendo y escribiendo archivos JSON.
